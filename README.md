# ZUPPO Website — Version 1 starter

## Files
- `index.html` — page structure
- `style.css` — responsive visual design
- `script.js` — category filters and search

## Preview on Android
1. Extract this ZIP file.
2. Open the extracted `index.html` in a code editor such as Acode.
3. Use the editor's Preview option to view the website.

## Publish
Upload the three files to a GitHub repository, then connect that repository to Cloudflare Pages. Choose the root directory as the build output directory; no build command is required.

## Important
- This is a first working website version, not yet a fully tested commercial launch.
- Platform links point to the listed platforms' public websites.
- The bottom advertisement area is currently a placeholder, not a live ad. Apply to an ad network and follow its policies before displaying paid ads.
- Check all platform links, brand usage permissions, privacy/terms requirements and mobile behavior before public promotion.
- ZUPPO does not process orders or payments. Shopping is completed on each platform's own website.
